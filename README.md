# Superstore-Sales-Dashboard-Power-BI
Project Overview

This project was completed as part of the AnalystLab Africa Data Analytics Internship (Week 4).

The objective was to transform raw sales data into an interactive dashboard that enables business stakeholders to monitor key performance indicators, identify sales trends, and make data-driven decisions.

⸻

Dataset

Dataset: Superstore Sales Dataset

The dataset contains transactional sales records including:

* Orders
* Customers
* Products
* Categories
* Regions
* States
* Sales
* Profit
* Discounts
* Shipping Details

⸻

Project Objectives

The dashboard was designed to answer key business questions, including:

* Which region generates the highest sales?
* Which category is the most profitable?
* Which customer segment contributes the most revenue?
* How do sales change over time?
* Which products drive the highest sales?
* Which states generate the highest revenue?

⸻

Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling

⸻

Data Preparation

The following steps were completed before visualization:

* Imported the Superstore dataset into Power BI
* Cleaned and transformed the data using Power Query
* Corrected data types
* Converted date fields
* Created a Date Table
* Built relationships between tables
* Created DAX measures for KPIs

⸻

Key Performance Indicators (KPIs)

The dashboard includes:

* Total Sales
* Total Profit
* Total Orders
* Total Customers
* Profit Margin

⸻

Dashboard Features

The dashboard contains:

* KPI Cards
* Sales by Category
* Sales by Region
* Profit by Segment
* Monthly Sales Trend
* Top 10 Products
* Sales by State
* Interactive Filters
* Date Slicers

⸻

Key Insights

* Technology recorded the highest sales among all product categories.
* The West region generated the highest overall sales.
* Consumer customers contributed the largest share of sales.
* Sales performance varied across regions and product categories.
* Interactive filtering enables users to analyze performance by year, region, category, and customer segment.

⸻

Recommendations

* Increase investment in high-performing product categories.
* Strengthen marketing campaigns in top-performing regions.
* Develop retention strategies for high-value customer segments.
* Monitor monthly sales trends to improve forecasting.
* Use dashboard insights to support business decision-making.
